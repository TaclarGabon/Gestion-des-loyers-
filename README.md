# Gestion des loyers V1.1

Version autonome corrigée pour GitHub Pages et pour l'ouverture directe sur téléphone.

## Correction principale

Le CSS et le JavaScript sont intégrés directement dans `index.html`.  
Les boutons OKALA, LANGLEY, Sandrine et Nelly fonctionnent donc sans dépendre de fichiers externes.

## Installation GitHub

1. Décompresser le ZIP.
2. Envoyer `index.html` à la racine du dépôt GitHub.
3. Activer GitHub Pages depuis la branche `main`, dossier `/root`.

## Confidentialité

Les données sont sauvegardées uniquement dans le navigateur avec `localStorage`.
Les images sélectionnées ne sont pas envoyées sur GitHub ni stockées en ligne.
